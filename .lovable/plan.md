# Ultra-professional CUBAFOOD.CA front page

## Goal
Refine the existing long-form homepage into a premium documentary-led public headquarters without changing the validated routes, factual content, or visual identity.

## Changes
- Recompose the opening screen for stronger brand recognition, clearer mission, honest project status, and immediate Cuba/Canada participation paths.
- Improve the page’s editorial rhythm: reduce repetitive chapter framing, sharpen typography and hierarchy, and alternate immersive field media with concise information bands.
- Turn the strongest existing content into a focused story: mission, Matanzas scale, current development status, land-to-family model, people needed, documented field work, infrastructure needs, and participation.
- Preserve all integrity safeguards: no invented partners, approvals, outcomes, quantities, testimonials, or fundraising claims.
- Polish interaction and accessibility across phone, tablet, and desktop while retaining FR/EN/ES switching and the existing header/footer.
- Add unique complete homepage metadata and verify links, layout, console health, and the latest build status.

## Technical details
- Work primarily in the homepage route, with only targeted global style additions where reusable editorial effects are needed.
- Reuse the existing video/poster assets, content modules, route links, and design tokens.
- Test at 390px, 768px, and 1440px viewport widths using the live preview.
